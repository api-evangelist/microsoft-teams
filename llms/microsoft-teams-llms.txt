# Microsoft Teams

> Microsoft Teams is a collaboration platform that combines workplace chat, meetings, file storage, and application integration. Teams is programmed primarily through Microsoft Graph (teams, channels, messages, tabs, apps, members, online meetings, and calls), the Bot Framework for conversational bots, incoming webhooks/connectors, and the real-time communications (calling/meeting) APIs. Authentication is OAuth 2.0 via the Microsoft Identity Platform (Entra ID) using Microsoft Graph permissions/scopes.

## APIs

- [Microsoft Graph Teams API](https://learn.microsoft.com/en-us/graph/api/resources/teams-api-overview): Core REST API for teams, channels, messages, tabs, apps, members, meetings, and calls. Base URL https://graph.microsoft.com/v1.0
- [Microsoft Teams Bot Framework API](https://learn.microsoft.com/en-us/microsoftteams/platform/bots/what-are-bots): Conversational bots in Teams via the Bot Framework.
- [Microsoft Teams Webhook and Connector API](https://learn.microsoft.com/en-us/microsoftteams/platform/webhooks-and-connectors/what-are-webhooks-and-connectors): Incoming webhooks and Office 365 connectors to post messages/notifications.
- [Microsoft Teams Real-Time Communication APIs](https://learn.microsoft.com/en-us/graph/api/resources/communications-api-overview): VoIP calls, group calls, IVR flows, and online meetings.

## Authentication

- [Authentication overview](https://learn.microsoft.com/en-us/graph/auth/): OAuth 2.0 (Microsoft Identity Platform). Authorize https://login.microsoftonline.com/common/oauth2/v2.0/authorize, token https://login.microsoftonline.com/common/oauth2/v2.0/token
- [Permissions (scopes) reference](https://learn.microsoft.com/en-us/graph/permissions-reference): e.g. Team.ReadBasic.All, Channel.Create, ChannelMessage.Read.All, ChatMessage.Send, OnlineMeetings.ReadWrite.All, Calls.Initiate.All.
