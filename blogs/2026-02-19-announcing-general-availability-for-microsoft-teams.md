This release introduces the first-ever Virtual Desktop Infrastructure (VDI) optimization for Microsoft Teams on Amazon WorkSpaces for Windows endpoints, delivering a seamless, high-performance collaboration experience. A First for AWS Customers Previously, Amazon WorkSpaces users did not have access to a fully optimized Teams experience. With this release, AWS environments now offer VDI support for Teams , bringing long-requested capabilities to both Personal and Pool Windows WorkSpaces client configurations.
